# Templates

Everything lives in `templates/` (npm workspace `@eliseo-arevalo/templates`). Run commands from that folder. All compositions are 1080×1920 at 30 fps. Example copy is in Spanish (voseo) for a fictional "sales notebook" app called *Demo App*; replace it with your own (see "Adapt a template").

| Composition id | Length (placeholder voice) | What it is | Timeline |
|---|---|---|---|
| `PromoVertical` | ~45 s | Feature promo: hook, problem, 5 feature scenes, summary, end card. | **Adaptive**: each scene is as long as its voice line + lead/tail frames (`buildTimeline` in `src/kit/timeline.ts`). Any voice works. |
| `ReelProblemSolution` | ~32 s | Hook → long problem beat → solution → relief → end card. | **Fixed frames**, with cuts tied to words of the hook line. |
| `ReelProblemSolutionNoMusic` | same | Same reel without the music bed, for QA only. Never deliver it. | |
| `SketchCharacters` | ~20 s | Sketch with two talking characters (character-kit rig, lip-sync). | **Fixed frames**; mouth shapes from `lipsync.json`. |
| `EndCardDemo` | ~6 s | The closing card alone: brand line, big QR, store badge, small socials. | Fixed. |
| Screen tour | any | `examples/demo-usability` + screen-kit (Playwright capture, virtual camera, lint). | JSON scenes. |

## Structure of a template

```
src/<template>/
  content.ts        all on-screen copy (and colours of this video if any)
  timeline.ts       scene frames; beats expressed in seconds of the voice lines
  scenes.tsx        one React component per scene
  <Template>.tsx    montage: scenes + wipes + audio tracks
  voManifest.ts     GENERATED by `npm run audio`: measured frames of every voice line
audio/<template>.json   voice lines, SFX list, music length, optional "fit" (max frames per line)
src/kit/                shared pieces (EndCard, QrCode, Camera, Words, Transition, Phone, Notebook, …)
src/characters/         character specs for the sketch (neutral demo people)
```

## Adaptive vs fixed timelines

- `PromoVertical` is safe with any voice or language: change a line, run `npm run audio -- promo`, scenes re-time.
- Reel and sketch have shots tied to *words* ("cut to the cash on the word 'charge'"). After changing voice, speed or text, check the beats at the frames listed in `timeline.ts` and adjust the numbers (they are written as seconds of the voice line, e.g. `w(1.41)`). `audio/<name>.json` has a `fit` map: a line longer than its target frames is sped up (ffmpeg `atempo`, max 1.45×) so slower voices still land on the shots. Prefer to rewrite the line shorter than to speed it up past ~1.25×.

## Adapt a template to your video

1. Pick the closest template; copy its folder (`src/reel` → `src/reel-mine`) and its `audio/*.json`; register the composition in `src/Root.tsx`.
2. Write the copy in `content.ts`, the voice lines in the audio JSON (use `{name}` for the brand's spoken name).
3. Edit `timeline.ts` frames to the story; reuse `src/kit` pieces; draw new things as SVG (no emoji, no stock imagery).
4. `npm run audio -- <name>` → `npm run studio` → review frames ([STYLE-RULES](STYLE-RULES.md)) → `npm run master`.

## Brand

`src/tokens.ts` only re-exports `brands/<id>/tokens.ts`. Switch with `npm run brand -- <id>`. A brand folder has `brand.json` (id, name, pronunciation, tagline, handle, storeUrl, storeLabel, voiceLanguage) and `tokens.ts` (colours, fonts, `brand`). The end card builds the QR from `storeUrl`, shows a drawn store button (or your official badge image placed in `public/`, unmodified) and the handle. Keep real brands out of this repo.

## End card as a component

```tsx
import { BrandEndCard } from "./kit/EndCard";
<BrandEndCard /* brand line, qr={{ url }}, store={{ label | badgeSrc }}, socials */ />
```
The layout follows the style rule: everything centred, QR and badge large, socials small, inside the safe zone. See `src/endcard/EndCardDemo.tsx`.

## Screen tour

```bash
cd examples/demo-usability
npx playwright install chromium     # once
npm run capture && npm run lint && npm run render
../../templates/scripts/audio/add-audio.sh out/demo-1920x1080.mp4 out/demo-final.mp4        # music bed; add --vo=line.wav@2.5 for narration
```
Screen-kit renders video only; `add-audio.sh` adds a music bed (synthetic by default), ducks it under optional voice lines and masters to −14.5 LUFS. Deliver the output of `add-audio.sh`, not the silent render.
