# Plantilla de brand kit

1. Copiá esta carpeta a `brands/<id>/` (o a un repo privado de marca).
2. Renombrá `brand.json.example` → `brand.json` y completá.
3. Creá `tokens.ts` con colores tipados + loaders de fuente.
4. Poné logos en `logo/`.
5. Documentá anti-patrones y nombre oficial.

Brand kit = **datos**. El código de animación va en `packages/motion-kit`.
Las marcas reales con assets propietarios viven en repos privados, no en este kit público.
