# Ejemplo — demo-wipes

Composición ficticia que demuestra las primitivas de `@eliseo-arevalo/motion-kit`:

- `SceneWipe` (`diagonal` | `circle` | `up` | `side`)
- `Reveal`, `Sticker`, `Check`
- formatos `VERTICAL_9_16`

**Sin marca real** — paleta y copy inventados para el kit público.

## Studio

Desde la raíz:

```bash
npm install
npm run studio:demo-wipes
```
